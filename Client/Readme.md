# 🏨 RooMantra (Frontend)

Welcome to the frontend repository of **RooMantra**, a modern and responsive Hotel Booking application. This project demonstrates complex UI/UX implementation, state management, and routing using the React ecosystem.

> **Note:** This repository contains the **Frontend only**. The application currently uses static/mock data to simulate database interactions.

## ✨ Key Features

### 🎨 User Interface (UI)
* **Modern Home Page:** Features a hero section, popular destinations, and testimonials marquee.
* **Room Browsing:** Grid layouts to display hotel rooms with amenities, pricing, and rating systems.
* **Room Details:** Dynamic product pages showing image galleries, host info, and location details.
* **Responsive Design:** Fully optimized for Mobile, Tablet, and Desktop using **Tailwind CSS**.

### 🛠️ Functionality
* **Dynamic Routing:** Utilizes `react-router-dom` for seamless navigation between pages (Home, Rooms, Booking, Admin).
* **Booking Simulation:** A "My Bookings" page that visualizes how booking history looks using mock data.
* **Admin Dashboard UI:** Includes a nested layout for hotel owners to view the dashboard, add rooms, and list rooms.
* **Context API:** Manages global application state (like user login status).

## 🛠️ Tech Stack

* **Framework:** React.js (Vite)
* **Styling:** Tailwind CSS
* **Routing:** React Router DOM
* **Icons:** Local assets & SVG icons
* **Data Source:** Static JSON / Mock Data (`assets.js`)

## 🏁 How to Run Locally

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/your-username/RooMantra-Frontend.git](https://github.com/your-username/RooMantra-Frontend.git)
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd RooMantra-Frontend
    ```
3.  **Install dependencies:**
    ```bash
    npm install
    ```
4.  **Start the server:**
    ```bash
    npm run dev
    ```
